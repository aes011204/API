# Dungreed — 모작 프로젝트

《Dungreed》를 C++ / Win32 API로 구현한 2D 액션 게임 모작 프로젝트입니다.

플레이어 이동과 전투, 보스 패턴, 장비·인벤토리, 상점 및 타일 맵 에디터를 구현했습니다. 용도별 Collider를 활용한 충돌 판정과 월드·화면 좌표 변환을 적용한 카메라 및 맵 편집 기능 제작에 중점을 두었습니다.

## 주요 구현

- 게임 루프와 시간·입력·씬·오브젝트·리소스 관리 구조를 갖춘 Win32 API 기반 2D 게임 프레임워크
- 이동·점프·대시 및 근거리·원거리 전투
- Body·Attack Collider를 구분한 이동·공격·피격 판정
- 상태 기반 행동 전환과 회전 탄막·낙하 검·레이저 패턴을 적용한 보스전
- 무기·액세서리 장착, 장비 세트 전환, 인벤토리 및 상점 시스템
- 월드·화면 좌표 변환, 타일 컬링, 배치·영역 채우기·저장을 지원하는 맵 에디터

## 참고

학습 및 포트폴리오 목적으로 제작한 비공식 모작 프로젝트입니다. 원작의 명칭과 게임 에셋에 대한 권리는 각 권리자에게 있습니다.
